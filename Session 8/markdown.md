A fluid layout usese relative units like percentages, rather than fixed units like pixels or points. This allows the layout to adapt to the screen size of the deice.

## Pillar - 2
- Media queries
Media queries are a CSS technique introduced in css3 that allows you to apply styes based on the characteristics of the device rendering the content ,such as its width, height, orientation , and resulation. This enables developrs to creat responsive designs that adjust to different screen sizes and devices.
